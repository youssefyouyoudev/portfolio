# Ethical backlink plan for youssefyouyou.com

## Purpose

Build relevant, earned references to the portfolio and its technical work. Every link should help a real reader discover useful work; none should be bought, automated, or fabricated.

## Priority actions

1. Update the GitHub profile with the canonical portfolio URL and concise Laravel/React positioning.
2. Add accurate portfolio links to public repository READMEs only where the repository is genuinely related.
3. Add the portfolio, ERPlus case study and RiFiTV work (where attribution is appropriate) to LinkedIn Featured and project entries.
4. Link ERPlus and RiFiTV only from their official sites or documentation when the owner approves and the relationship is accurate.
5. Publish first-hand implementation articles on Dev.to or Hashnode, each linking naturally to the matching portfolio case study.
6. Seek genuine Moroccan developer or business directories with editorial standards; use Nador/Morocco wording without implying a local office elsewhere.
7. Pitch technical guest articles based on real lessons: Laravel API/dashboard architecture, Laravel/Vite/Nginx deployment, and Excel/VBA-to-web-app decisions.
8. Ask real collaborators or clients for a reference only with their explicit permission and only after confirming the wording.

## Page-to-topic targets

| Portfolio page | Natural referral topic |
| --- | --- |
| ERPlus | Laravel ERP, React dashboard, business systems |
| RiFiTV | Laravel/Vite/Nginx deployment and media UX |
| Digital Archiving | administrative digitalization and document workflows |

| Services | Laravel APIs, React/Next.js interfaces, dashboards |

## Quality rules

- Prefer relevant, editorially controlled pages over high-volume listings.
- Use descriptive, natural anchors; avoid repeated exact-match anchor text.
- Record source, destination, date, owner permission and status in a private outreach tracker.
- Do not use PBNs, spam directories, forum signatures, fake comments, paid bulk packages or invented partner/client references.
